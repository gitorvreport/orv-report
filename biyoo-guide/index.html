팀 배포 안내 · 버전 1.0.12

비유 펫은 아침 업무를 이렇게 도와요

  1. 출근해서 PC 켜기

    비유가 자동으로 켜져 바탕화면에 나타나요

  2. 오늘 확인할 작업 보기

    할 일, 오늘 마감, 마감이 지난 일을 대화 카드로 보여 줘요

  3. 평소 말투로 답하기

    “UI 아이콘은 오늘 끝낼게”처럼 말하면 돼요

  4. Jira에 바로 반영

    상태와 날짜가 바뀌고, 마감일을 바꾼 사유는 코멘트로 남아요

비유에게 이런 도움을 받아요

오늘 할 일 알림

아직 시작하지 않은 작업을 출근하자마자 보여 줘요

마감 초과 챙기기

마감이 지난 작업을 따로 모아 놓치지 않게 알려요

말 한마디로 처리

작업 이름으로 편하게 말하면 상태와 날짜가 바뀌어요

날짜 고치기

시작일·마감일을 ‘금요일’, ‘내일’로 바꿔요

내 작업·검색

내 작업, 파트별·담당자별 작업을 찾아 줘요

문서·새 작업

Confluence 문서를 찾고 새 Jira 작업을 만들어요

1

설치 파일 실행

Biyoo-Pet-Setup-1.0.12.exe를 더블클릭해요. 관리자 권한은 필요 없어요

2

보안 경고가 뜨면

‘Windows의 PC 보호’ 창에서 추가 정보를 누른 뒤 실행을 눌러요

3

비유 등장

바탕화면 오른쪽 아래에 비유가 나타나요. 다음부터는 PC에 로그인하면 자동으로 켜져요

Slack에서 비유 봇을 꼭 즐겨찾기 해 주세요

  1. 비유 봇 DM 열기

    Slack에서 비유 봇과의 다이렉트 메시지를 열어요

  2. ⭐ 즐겨찾기 등록

    DM을 즐겨찾기에 추가하면 넛지와 답장을 언제든 바로 열 수 있어요

  3. VIP 등록

    비유 봇을 VIP로 등록해 알림을 놓치지 않게 해요

비유 펫과 Slack 비유 봇 DM은 같은 대화예요. 펫을 꺼 둔 날에도 Slack에서 넛지를 이어서 처리할 수 있어요

02

아침 넛지

마감이 다가오거나 지났는데 끝나지 않은 일을 비유가 먼저 알려요

넛지가 뭔가요?

넛지

마감이 임박하거나 이미 지났는데 아직 완료되지 않은 내 일감을 비유가 알려 주는 알림이에요

마감 임박

오늘이나 곧 마감인데 아직 완료되지 않은 일감이에요

마감 초과

마감일이 지났는데 아직 완료되지 않은 일감이에요

완료하면 빠져요

완료로 바꾼 일감은 넛지에 다시 나오지 않아요

출근하면 오늘 확인할 작업을 보여 줘요

  1. 할 일

    아직 시작하지 않은 작업이에요. 오늘 시작할 작업을 골라요

  2. 🔥 오늘 마감

    오늘까지 끝내야 하는 작업에 붙는 표시예요

  3. 마감 초과

    마감일이 지난 작업이에요. 끝냈다면 완료로, 아니면 새 마감일을 정해요

  4. 편하게 답하기

    카드에 바로 답장하면 돼요. Slack 비유 봇 DM에 답한 것과 같아요

평소 말투로 답하면 비유가 알아들어요

이렇게 말하면비유가 하는 일
UI 아이콘은 오늘 시작해서 금요일까지 할게진행 중 + 마감일 설정
전투복 모델링 끝났어완료 처리 (작업은 검수 요청으로)
텍스처 보완은 다음 주 금요일로 미뤄 줘마감일 변경, 사유를 물어봐요
전투복은 8일 정도 걸릴 것 같아8영업일 뒤로 마감일 계산
1번 완료, 2번 내일까지번호로 말해도 돼요
확인바꿀 것 없이 확인만 했다고 남겨요
종료오늘 넛지를 마쳐요

여러 작업을 한 번에 말하면 먼저 확인받아요

작업 이름으로 말하거나 여러 작업을 한 문장에 담으면, 비유가 바꿀 내용을 먼저 보여 주고 확인을 받아요

응보여 준 대로 진행해요
2번 빼줘그 작업만 빼고 다시 확인받아요
취소아무것도 바꾸지 않아요
다른 말새 요청으로 다시 이해해요
확인은 5분 동안 기다려요. 지난 날짜나 마감일보다 늦은 시작일은 실행 전에 걸러 줘요

마감일을 바꿀 땐 사유를 함께 남겨요

  • 사유를 입력해야 마감일이 실제로 바뀌어요
  • 사유는 Jira 코멘트로 자동 기록돼요
  • ‘취소’라고 하면 기존 마감일을 그대로 둬요
  • 주말·공휴일은 다음 영업일로 맞춰요

넛지는 이렇게 마무리돼요

종료라고 말하기

‘종료’, ‘끝’이라고 하면 남은 항목이 있어도 바로 마쳐요

모두 처리하기

넛지의 작업을 모두 처리하면 자동으로 끝나요

오후 5시까지 답이 없으면

그날 넛지는 자동으로 끝나고, 다음 날 새 넛지가 와요

알아듣지 못한 답이 5번 넘으면

넛지가 끝나요. 그 뒤에는 평소처럼 대화하면 돼요

넛지를 내 하루에 맞게 설정해요

  1. 로그인 시 자동 실행

    켜 두면 출근해 PC를 켜자마자 비유가 오늘 확인할 작업을 보여 줘요. 기본으로 켜져 있어요

  2. 넛지 한 번 더 확인할 시각

    오후에 아직 처리하지 않은 작업만 한 번 더 챙겨 받아요. 사용 안 함, 11:00, 13:00(기본), 15:00, 16:30

  3. 지금 넛지 확인

    언제든 남은 넛지를 바로 불러와요. 없으면 이유를 짧게 알려 줘요

04

문제가 생기면

자주 겪는 증상과 해결 방법

넛지 문제

출근했는데 넛지가 안 보여요

로그인 시 자동 실행이 켜져 있는지 보고, 우클릭 → 지금 넛지 확인을 눌러요

‘오늘 넛지가 없어요’라고 나와요

오늘 확인할 작업이 없는 거예요. 넛지 대상인지 궁금하면 PM팀에 물어봐요

비유가 내 말을 잘못 알아들었어요

확인 단계에서 ‘취소’라고 하면 아무것도 바뀌지 않아요. 작업 이름을 넣어 다시 말해요

Slack 넛지와 펫 카드가 둘 다 와요

같은 넛지예요. 펫이나 Slack 어느 쪽에서 답해도 똑같이 처리돼요

설치·연결 문제

설치할 때 ‘Windows의 PC 보호’ 창이 떠요

추가 정보를 누르고 실행을 눌러요. 서명 인증서 없이 만든 사내 배포 파일이라 뜨는 경고예요

‘봇 서버에 연결하지 못했어요’가 나와요

사내망이나 VPN에 연결돼 있는지 확인하고 다시 보내 주세요

인증 코드가 오지 않아요

Slack의 비유 봇 DM을 확인해요. 없으면 비유에게 “코드 다시 보내 줘”라고 말해요

이메일을 바꾸고 싶어요

비유에게 “이메일 변경”이라고 말하고 새 이메일로 다시 인증해요

화면·동작 문제

비유가 보이지 않아요

작업 표시줄 오른쪽 트레이의 비유 아이콘을 눌러요. 최소화된 상태일 수 있어요

비유를 눌러도 반응이 없어요

우클릭 메뉴에서 ‘항상 위’를 켜요. 메모 앱처럼 늘 위에 뜨는 창과 겹치면 비유를 옆으로 옮겨요

비유가 작업 표시줄에 겹쳐 있어요

비유를 끌었다 놓으면 화면 안으로 돌아와요. 계속되면 ‘진단 정보 복사’로 알려 주세요

답에 버튼이 있다고 나와요

버튼은 Slack의 비유 봇 DM에서 눌러 주세요

그래도 해결되지 않으면 알려 주세요

진단 정보 복사

비유를 우클릭하고 ‘진단 정보 복사’를 눌러요

PM팀에 보내기

PM팀에 Slack으로 증상과 함께 붙여 넣어 보내요

오류 기록 첨부

pet-error.log 파일도 함께 보내요. 위치는 %APPDATA%\desktop_bot 폴더예요

진단 정보에는 화면 크기와 비유 위치, 설정만 들어가요. 이메일과 인증 정보는 들어가지 않아요
