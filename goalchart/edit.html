📋 편집본 사용법 (열기)
  1. 작업 막대나 왼쪽 이름을 클릭하면 이름·담당·기간·상태·선행작업을 편집합니다. 선행 작업 목록에는 같은 에픽의 작업만 나옵니다.
  2. 왼쪽 행이나 에픽 헤더에 마우스를 올리면 ▲▼로 순서를 바꿉니다. 작업은 같은 에픽 안에서만 움직이고, 에픽 헤더의 ▲▼는 에픽을 통째로 옮깁니다.
  3. 에픽 헤더의 +/−로 접고 펼치며, 왼쪽 목록과 타임라인 경계를 끌어서 폭을 조절합니다. 막대 이름이 잘리면 「글자 전체」로 전부 표시합니다. 이 설정은 브라우저에 기억됩니다.
  4. 상태를 '완료'로 바꾸면 그 작업을 기다리던 후행 작업의 '선행 대기' 표시가 풀립니다.
  5. 편집을 마치면 JSON 내보내기 → 그 파일로 data/chart.json 교체 → npm run deploy 순으로 배포판에 반영합니다.
편집본입니다. 변경사항은 브라우저 메모리에만 있으니 ‘JSON 내보내기’로 저장한 뒤 data/chart.json을 교체하세요.
